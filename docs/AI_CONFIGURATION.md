# AI 配置说明书

简体中文 | [English](AI_CONFIGURATION.en.md) · [返回 README](../README.md)

适用于 Stock King 2.6。界面菜单以中文为主。行情、自选、本地精选与量化研究不要求 AI API Key；AI 用来整理证据、解释风险和比较观点，不替代本地入场检查。

优先使用免费本地流程：不启用 AI、使用下文 Ollama，或手动导入已有报告。云端配置仅供已有需求的用户自行接入，不是安装或日常研究的前提；软件不要求购买任何云端 AI 套餐。

## 1. 添加并保存平台

1. 打开 **工具 → AI 平台配置 → 添加AI配置**。
2. 填写配置名称、接口地址、令牌、模型名称。名称是本机标签；模型名称须是 API 的准确 Model ID。
3. 点击 **测试并刷新模型列表**，选择当前账号有权限的模型。服务商不提供模型列表时，可手动输入准确 ID；列表失败本身不能证明生成接口不可用。
4. 在抽屉里点击 **确定**，回到配置列表后点击 **保存配置**。只点“确定”尚未持久保存。
5. 返回 **AI 研究**，选择平台、模型和股票，再手动运行一次研究以验证生成接口。精选候选的证据可供参考；如需模型解读，请在 **AI 研究** 中独立发起。

另一入口是 **设置 → AI设置 → AI诊股 → 前往管理**。这里的旧开关不替代上述平台配置，也不代表定时精选会自动调用模型。

## 2. 字段与示例

| 字段 | 含义与建议 |
| --- | --- |
| 配置名称 | 自定义标签，如 `DeepSeek-研究`、`本地 Ollama`；用来区分平台。 |
| 接口地址 | API Base URL。不要填聊天网页，不要额外添加 `/chat/completions`；保留服务商要求的版本前缀。 |
| 令牌 | API Key，仅在本机输入。聊天账号登录状态不等于 API 凭据。 |
| 模型名称 | 从模型列表选择，或输入服务商/本地模型实际 ID；不要照抄已经下线的默认模型名。 |
| Temperature | 采样参数；证据整理可从较低值开始。部分模型限制或忽略该参数，按服务商说明调整。 |
| MaxTokens | 最大输出量，不能超过当前模型/接口限制；模型列表信息不完整时需手动核对。 |
| Timeout | 超时，单位为秒，界面最小值为 60。长报告或推理模型可适当提高。 |
| 深度思考 | 只在模型及接口支持时开启。不同“OpenAI 兼容”服务并不保证推理扩展参数相同。 |
| HTTP代理 | 需要代理时开启并填地址。列表测试使用通用 HTTP 客户端；请以实际生成请求确认该配置的代理链路。 |

### 云端 OpenAI 兼容服务

以 DeepSeek 为例：配置名称可填 `DeepSeek-研究`，Base URL 填 `https://api.deepseek.com`，API Key 使用本人在对应 API 平台创建的密钥，模型从当前账号返回的列表选择。具体模型、参数及计费以 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 为准。

其他服务按其文档填写基址（有的要求 `/v1`）和准确模型 ID。应用使用 Chat Completions 格式；仅支持其他协议的服务需要适配，不能仅凭“兼容 AI”名称认定可用。配置页出现某平台名称也不代表所有部署形式都已验证。

### 本地 Ollama

| 字段 | 示例 |
| --- | --- |
| 配置名称 | `本地 Ollama` |
| 接口地址 | `http://localhost:11434/v1` |
| 令牌 | `ollama`（本地默认服务忽略此占位值；应用表单要求非空） |
| 模型名称 | `ollama list` 中已经安装的准确模型标签 |
| 深度思考 | 初次验证时关闭，再按模型兼容性调整 |

先安装并启动 Ollama、下载适合机器内存的模型，然后在终端用 `ollama list` 确认模型存在。模型未下载时，仅填写名字无法运行。若服务另有认证代理，应使用该代理的真实认证方式，不能把占位值当成凭据。接口范围见 [Ollama OpenAI 兼容说明](https://docs.ollama.com/api/openai-compatibility)。这是一组配置示例，不代表每种本地模型都已通过 Stock King 实测。

## 3. 页面中的 AI 使用方式

**AI 研究：** 选择股票和模板，检查提取证据的时间与缺口，再选择平台/模型并运行。保存、比较报告时同时查看分析时间、有效期、来源和待核验标记。模型文字不能把缺失行情变成已验证事实。

**精选 → 当日机会：** 本地扫描展示稳健/均衡/激进条件与候选证据。需要模型整理证据、风险或分歧时，在独立的 **AI 研究** 页面手动选择股票运行；研究结果不改变本地排名或绕过入场条件。

**外部报告：** AI 研究支持导出研究包，然后手动导入外部 AI 生成的 Markdown、TXT 或 JSON 报告。按页面填写来源与时间信息，检查解析结果及待核验项。该路径不要求在软件里保存远程模型密钥；你将导出的研究包提交给其他服务时，仍需自行决定分享范围。

## 4. 数据与费用

- 配置保存在本机应用数据中，不应当作操作系统密钥保险箱。不要提交配置数据库、`.env` 或真实密钥到 GitHub，也不要分享含密钥的截图。
- 使用远程 AI 时，选中的研究证据、提示词和请求内容会发送给对应服务商；“本地保存”不代表“AI 请求不出网”。本地 Ollama 示例指向本机服务。
- 日常定时精选、复盘和本地学习不因添加平台而自动使用远程 AI。主动启用的机器人、研究助手或其他 AI 计划任务应分别检查设置。
- API 费用和配额由服务商管理。先进行一次范围较小的手动研究，检查服务商用量记录，再决定是否增加输出长度或使用推理模型。

## 5. 常见错误

| 现象 | 检查顺序 |
| --- | --- |
| 模型列表测试通过，生成失败 | 列表测试只调用 `/models`。核对模型生成权限、模型 ID、余额、输出限制、推理参数，以及生成请求的实际错误。 |
| 列表为空或列表接口 404 | 检查基址和版本前缀；服务可能未实现模型枚举。确认官方 Model ID 后手动填写，再测试生成。 |
| 401 / 403 | 核对密钥所属平台、有效性及模型访问权限；不要在问题报告中粘贴密钥。 |
| 404 / model not found | 检查是否误填聊天网页、重复路径或错误 Model ID；某些服务用同一状态码表示不同错误，以响应内容为准。 |
| 429 / quota / balance | 按错误内容区分限流与配额/余额问题；不要靠快速重试解决。 |
| Timeout / 网络错误 | 确认服务运行、DNS/网络和所需代理；本地服务检查端口与模型加载。推理耗时较长时再合理提高 Timeout。 |
| unsupported parameter | 检查服务兼容范围，先关闭深度思考并调整采样/输出参数；仍不兼容时需要接口适配。 |
| 重启后配置消失 | 确认点击了列表页“保存配置”，并仍在同一个本机数据目录/系统用户下运行。 |

排查时只提供去除密钥和个人数据后的错误内容、平台名称、模型 ID、软件版本和操作步骤。
