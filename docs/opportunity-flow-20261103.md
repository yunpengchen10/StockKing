# 机会精选：板块资金、持续走势与买入位置

策略版本：`opportunity-flow-20261103-v1`。本次替换「机会精选」现行 E/M 规则；历史 E/M 推荐保留原版本、原价格和原依据。下方模型验证精选不因此获得新的模型验证资格。

## 为什么修改

1—5 分钟价格加速、短时放量和瞬间突破容易把已拉升的股票排到前面，也容易漏掉缓慢推进或正常整理的股票。新版不要求 1、3、5 分钟涨幅为正，不以涨速、加速度或绝对资金规模作为最终排序依据。短时价格指标可保留为诊断，不能替代资金证据。

资金数据仍是供应商依据成交分类得到的估算，不是可识别机构账户的真实资金。不能把股价上涨标记的成交额、外内盘、新闻或题材热度写成已确认资金流入。

## 从发现到推荐

### 全市场发现

- 分页读取全沪深 A 股的同源累计资金净额、成交额和供应商更新时间；分页缺失、重复、总数变化等异常不冒充完整市场。
- 资金发现可读取全沪深 A 股以核验行业全体成员；最终研究股票池仍为沪深主板，并排除名称含 ST、退、整理、停牌的记录。没有将创业板、科创板或北交所扩入最终推荐池。
- 用完整行业目录聚合，剔除候选自身；至少 3 只同行且同源有效覆盖不少于真实同行数的 80%。不把已筛出的上涨股票当成板块成分全集。
- 当日累计净额为正的板块及股票可获得约一半深研预算，其余仍由活跃度、状态变化及事件发现分配；不足时补足研究覆盖。这里的累计净额只分配研究资源，不授予推荐资格。
- 发现指标有自己的供应商时间；请求完成时间不能刷新它们的时效。

### 固定 30 分钟确认

最终确认采用预先固定的同一交易段 30 分钟窗口，不在 15/30/60 分钟之间事后挑最好看的结果。60 分钟仅作为辅助展示。早盘、午后尚未形成完整窗口时只观察，午休不拼接为连续分钟。

当前分钟端点合同从 09:31、13:01 开始；30 分钟价格路径及累计资金差分需要 31 个连续端点，因此通常最早约 10:01、13:31 才能形成该窗口。不会为提前发布而补造开盘基点；到时仍须满足数据覆盖和其他约束。

个股与板块资金必须来自相同供应商、相同计量版本、相同来源和同一窗口。以累计净额的差计算窗口净额，再除以精确 `(窗口开始, 窗口结束]` 的成交额。缺分钟、混源、单位异常、未来时间、冲突修订或成交额不匹配均不能补算成有效证据。

板块仍以完整同行分母核验至少 3 只、80% 覆盖。记录正流入成员占比，以及最大单只股票占正流入总额的比例，便于识别资金集中情况。

### 公开的初始研究约束

以下阈值是可检查的研究起点，**未经收益校准，也不代表已经提高胜率**。以代码 `flow_opportunity_policy.PARAMETERS` 为准。

| 条件 | 当前约束 |
| --- | --- |
| 个股和板块 30 分钟估算净额 | 均大于 0 |
| 个股正流入分钟占比 | 至少 50% |
| 同行正流入成员占比 | 至少 50% |
| 30 分钟净推进 | 大于 0 |
| 有方向的路径效率 | 至少 0.2；净对数变化 / 各分钟绝对对数变化之和 |
| 上涨回吐比例 | 不超过 0.5 |
| 30 分钟收盘路径最大回撤 | 以元计的最大「此前最高收盘价 − 此后收盘价」不超过最近已完成交易日 ATR14 的 0.75 倍 |
| 卖一价至 30 分钟最低价的距离 | 大于 0 且不超过 ATR14 的 1.5 倍 |
| 买卖点差 | 不超过 0.3% |
| 报价、盘口的供应商时间 | 距决策时点最多 30 秒，不允许未来时间 |
| 已完成分钟截止时间 | 距决策时点最多 299 秒；个股与板块资金须与该截止一致 |
| 每轮、每行业上限 | 每轮最多 5 只，每行业最多 2 只，不凑数 |

ATR 必须来自最近已完成交易日，未复权昨收与当前报价昨收对齐。报价和盘口必须通过新鲜度与来源检查，当前分钟必须独立核验。已核验重大负面、不可买盘口、污损当前数据等仍可否决。

最近 5 分钟资金转弱或转负只显示为反向证据，不单独否决已满足 30 分钟约束的股票，也不用于排序。这样不会把几分钟波动再次变成主导开关。

### 排序与界面

通过约束的股票使用五个等权维度：板块净流入强度、个股净流入强度、正流入分钟占比、30 分钟路径效率、入场风险距离，每项权重 20%。资金强度为净额/同窗成交额；风险距离越小方向越优，其余维度越大方向越优。采用中位名次百分位：`(更差数量 + 0.5 × 同值数量) / 样本数量`。单一候选为 0.5，不自动获得 100 分。

剔除自身会令同一行业不同个股的板块强度略有差异。板块排名先取该行业合格候选所见强度的中位数作为统一比较值，再在不重复的行业之间计算百分位，避免候选输入顺序改变结果。逐股原值记为 `rawValue`，实际排名值记为 `rankValue`，均保留展示和审计；完全同分只按股票代码稳定排序。

`F-A` 表示通过当前研究约束，`B` 为待确认，`C` 为硬否决。正常短暂回落与缓慢上行均可入选。界面逐只展示资金窗口、来源、净额、强度、覆盖分母、入场 ATR 距离和排序分项。旧 `rankScore` 不再生成；`rankingComposite` 是 0—1 的本轮相对顺序，不是胜率、价格目标或收益预测。

## 归档、缺失和验证边界

- 原始累计资金从真实首次采集开始保存到独立 SQLite；记录来源、计量版本、行情时间及首次观察时间。历史没有的数据不会回填为当时已知。
- 来源修订不覆盖旧值；冲突单独保存，相关分钟隔离。历史读取同时限制行情时间和观察时间。
- 新规则不回写旧推荐，不把回放结果计作当时已发出的推荐。新版不调用旧版算法作为缺数据时的替代。
- 所有网络阶段受原扫描总截止时间约束。资金与同行分钟按研究队列的行业顺序优先完成真实成分采集；未完成数据明确缺失，不能降低分母或覆盖门槛。最终报价留到采集结束再请求。
- 测试验证计算、准入、时间边界、记录持久化及展示一致性，不能验证未来收益。真实效果应使用之后冻结的新推荐，按推荐时点后的可成交价格、T+1/T+3/T+5、成本和回撤，与同一时点可交易池的等权及随机基准比较。不能只比较当天开盘至收盘涨幅，也不能用新采集资金重写过去信号。
- 当前观察账本的 T+1/T+3/T+5 仍是参考价至后续收盘的毛变化，成交和成本未知，不能当作已经完成上述执行收益验证。
- 结构低点与 ATR 是风险尺度，不保证按该价退出。A 股 T+1 和跳空风险仍适用。

## 代码入口

- `fund_flow_discovery.py` / `recommendation_evidence.py`：资金发现及研究预算。
- `flow_collection.py` / `local_opportunities.py`：采集顺序、固定时间窗口及整条扫描接线。
- `fund_flow_evidence.py` / `fund_flow_archive.py`：同窗计算、完整同行覆盖及不可改写的资金证据。
- `minute_history.py` / `trend_evidence.py`：精确成交额窗口、30/60 分钟路径。
- `flow_opportunity_policy.py` / `opportunity_channels.py`：公开约束、排序及现行输出。
- `legacy_opportunity_channels_20261029.py`：仅供旧规则历史回放，现行入口无 fallback。
- `stock_king_display.py` / `opportunityDisplay.mjs` / `KingPicks.vue`：版本识别、历史只读及资金依据展示。
