# 集合竞价与开盘预案修复

本地精选在开盘前不再要求当日分钟信号。盘前使用独立条件推荐，盘中准入规则保留原有含义。

## 时段与依据

按北京时间、交易日历区分竞价前、09:15—09:20、09:20—09:25、09:25—09:30，以及09:30—09:35开盘衔接。09:35之后转回盘中扫描；已保存预案在页面自动标为历史。

- 研究队列优先纳入上一交易日保存的候选与次日观察，再用最近已完成交易日的20—60日历史重新核验，不直接复用旧推荐结论。
- 依据MA5/10/20、昨收、昨高、支撑、历史压力、ATR与可取得的历史成交量额形成最多5只条件推荐；已知业绩和解禁风险参与排除。未取得的事件证据明确列为缺口。
- 原始软件日线`volume_shares`与`amount_cny`分别按股和人民币元识别；不与未知单位的旧字段混填。
- 普通报价须有证券身份、来源、当天源时间且不超过30秒。不能用抓取时间代替源时间，不能推断竞价匹配价、匹配量或未匹配委托。
- 缺当前报价时仍可展示昨夜计划，但参考价明确为昨收。新鲜报价可核验价格是否失效；开盘成交还须核验开盘后的时间、OHLC与成交量额。
- 每只列出触发、支撑失效和不追条件。有已知压力时，不追上限采用`min((压力+支撑)/2, 压力-ATR14)`，表示压力空间至少覆盖支撑距离与ATR风险比较下限；这是未校准的研究条件，不是目标价、收益预测或成交承诺。

竞价阶段说明依据[上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。当前普通行情源不提供完整竞价撮合字段，因此始终明确显示竞价匹配尚未核验。

## 保存与边界

新结果保存在`premarketCandidates`与`premarketAssessment`；`candidates`继续表示原盘中候选。开盘预案不会进入正式交易入选计数或训练样本。原始扫描与预案均可从扫描历史恢复。

有效的昨夜日线允许预案在缺分钟、缺新报价时保存。全市场快照不可用时，可以使用上一交易日保存的股票目录重新研究；股票目录和旧报价均不作为当前成交证据。若昨夜日线也不可用，仍保留旧结果并说明实际缺口。

官方时点按目标时点选择研究路径，不能把09:40任务的提前准备误作盘前推荐。跨09:30按完成时的开盘阶段核验，跨09:35不再发布新开盘预案。日线不包含当日未完成K线，前收盘口径冲突、停牌或一字封板无可买成交时不作为当前可操作机会。
