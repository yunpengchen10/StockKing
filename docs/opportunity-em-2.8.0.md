# 2.8.0 机会推荐规则

## 2026-10-29 准入与同步修复

当前机会规则版本为 `opportunity-em-20261029-v2`。反转需有三分钟转正、已完成突破或收复确认，不能仅凭一分钟反弹入选。新鲜报价跌破信号窗口局部低点、跌回突破位，或突破失败与高点降低尚未修复时，取消推荐资格。价格加速与突破不再互相充当独立支持；累计买盘和无方向放量不能抵消同窗负资金，排序不再奖励负比较基线造成的虚增加速度。有证据的下跌日反转和结构保持的轻微回踩仍可评估。

推荐记录默认绑定当前精选的保存轮次，映射展示轮次 ID 与账本轮次 ID，并从该轮冻结的机会列表读取相同股票。切换页面或新扫描完成后更新名单，迟到的旧请求不能覆盖新结果；空机会榜不回退到其他观察名单。历史查询继续保留，旧版本只按原证据读取，不能重新生成交易或训练资格。参考价格变化始终以实际推荐价计算，首次研究发现价另行展示。

验证包括195项后端验收、144项前端测试、Go接口测试，以及冻结行情回归和同轮账本代码/参考价核对。测试中的市场片段只复现当时可见的结构缺陷，不包含账户或成交记录，也不证明修复后的未来收益。

本次依据用户要求向 ChatGPT 每日扫描的 E（早期启动）/M（主升确认）思路靠拢，不提高数值门槛。新增独立的机会精选；原模型验证通道继续保留，两者不混算验证成绩。

## 候选发现

- 主板研究预算仍按原来的约10%、至少300只分配。约一半保留活跃度、换手与开盘修复，另一半覆盖跨扫描改善、低位修复和已披露事件；缺失通道的容量返还，不机械凑候选。
- 跨扫描变化只能使用同源、同日、同连续交易时段、相隔不超过60分钟的真实快照。第一次扫描没有前一快照时，其他发现通道仍工作。
- 公开公告使用已有免费接口的最近100条，15分钟缓存，属于部分覆盖。标题只能形成待验证线索，不能冒充已核验利好或提升正面催化分。
- 缺少20日分钟历史的候选也采集当日分钟走势；历史补齐仍在原有独立流程中运行，当轮采集受既有时间预算约束。

## 机会判断

- E：已观察到加速、反转或突破，并有主动性、新催化或相对板块地位之一提供支持。当日短窗成交速度可以用于主动性评估，不依赖20日基准；不要求板块同步、完整历史、模型已训练、站回VWAP全部成立。
- M：跨窗口延续或回踩再起有当时证据，再结合主动性/催化/相对地位与价格结构确认。
- 单分钟小回撤记为反证并影响排序，不自动否决。剩余空间未知或创出新高时保持未知，不编造目标价，也不因此一票否决。
- 新鲜且无冲突的行情、实际存在正常卖盘仍是推荐基础。无买入窗口、污染或冲突数据、明确重大负面，以及转弱、结构破坏和卖压同时出现时停止入选。缺失确认不等同于重大反证。
- 每轮最多展示5只 E-A/M-A；无合格机会可以为空。排序分只表示当轮规则名次，不能解释为胜率或收益预测。

## 留档与检验

首次发现时间与当时参考价单独展示，不把分钟行情时间冒充首次触发时间。首次实际入选另设不可重置的机会推荐台账，早期观察价不得成为后来推荐的起算价。

机会推荐与对照样本分别记录 T+1、T+3、T+5 的参考价格变化；它们不是模拟成交净收益，不进入原正式交易模型训练集。旧快照重开时显示为历史记录，不改写原始时间、证据或参考价。真正的策略效果需要随后形成的前瞻记录评估。

完成且有真实当轮证据的零推荐会替换上轮榜单；全源失败、超时或无法形成有效评估时保留历史并显示状态。历史摘要仅用于定位，恢复展示前会读取完整结果再次核验。

自动任务使用新通道，时间表保持既有配置。14:55任务仍服从原14:57到期规则；手动盘中研究在15:00前可评估，不混用任务到期时刻。
