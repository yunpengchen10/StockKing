# Stock King v2.7.0

本版把推荐、复盘和学习改为按任务和数据版本运行，并修复推荐记录读取问题。

- 推荐记录修复 `Illegal invocation`；读取超时停止转圈，保留已有内容并支持重试。
- 分钟行情核对请求与响应证券身份，使用独立报价核验价格范围；冲突整日隔离，记录不可变前缀和核验可知时间。
- 当日入场T+1扣费收益、次日潜伏和延续价格事件独立拟合。加入Ridge收益基线、Logistic事件基线、LightGBM收益/事件/下侧分位模型及独立概率校准。
- 标签与特征采用同一时间口径；复盘自动补齐可取得证据。采用滚动开发、最终留出、前向影子验证和模型回退检查。
- 研究配置执行总预算、单股和行业上限；模型无优势时保留现金，未入选股票继续保留为对照。
- 学习页面分别展示检查、完成拟合、验证及启用时间。减少历史查询中重复读取整轮扫描载荷。

软件版本2.7.0与规则、模型版本分别记录。原历史推荐保留原始快照。样本不足或验证不通过时继续显示规则研究；本版软件测试不代表已经证明预测收益改善。

详细公式、标签、数据边界和发布门槛见 [算法说明](../algorithm-v270.md)。

## Windows 安装

下载 `Stock-King-Setup-x64-v2.7.0.exe`，关闭软件后覆盖安装到原目录。安装包包含本地引擎与离线WebView2；保留用户数据，不附带任何个人数据库或训练模型。安装程序没有Stock King代码签名，内置WebView2已验证微软签名。

可用同页 `SHA256SUMS.txt` 校验下载文件。安装及维护方法见 [Windows说明](../WINDOWS_INSTALL.md)。
