# 日线推荐 v3：排序证据、进攻观察与A股情绪诊断

算法标识：`king-daily-primary-v3`。桌面发行版本保持 2.7.0。

## 排序与观察范围

日线条件推荐保留报价、已完成日K、当日方向、披露风险及各风险档的准入检查。排序改为同档合格候选的两个经验名次等权组合：

- 开盘后价格推进：`(price - open_price) / completed_daily_ATR14`。
- 当日方向效率：`(price - open_price) / (high - low)`。
- 经验名次：`(count_less + 0.5 * count_equal) / eligible_peer_count`。
- 排序值：两个经验名次各占 0.5；成交金额只用于同分排序，股票代码用于最终稳定排序。

等权是未经效果验证的实验基线。排序值不表示上涨概率；单次快照不证明持续买盘或资金身份。

独立的 `dailyAttackWatchlist` 保留通过数据、方向及披露风险检查但未进入均衡主榜的观察对象，包括突破历史新高、缺少上方历史压力位的股票。观察对象不获得正式推荐、成交或训练资格，不补造目标价或结构盈亏比。弱市场状态仍明确保留。

研究队列依旧为主板池的约10%、至少300只且不超过实际股票数。未进入深研的股票不算已排除，观察池不是全市场涨停召回率的证明。

## 可复核记录

`dailyRejectionLedger` 保存每只深研股票的首个失败阶段、各风险档的准入原因、排名、比较样本数及入选状态。基础条件失败、均衡档拒绝、合格但排在名额外分别记录。

`dailyRankEvidence` 在完整和压缩信号记录中保存。SQLite投影采用分块 `json_set`，保留嵌套的显式 `null`，避免把未知概率或缺失指标删除。

## 情绪诊断

`emotionDiagnostics` 独立展示上涨家数占比、涨停占比、跌停占比、触板后当前未封比例、昨日涨停群体平均溢价及晋级率。每项记录来源时点、当前样本数、前60个交易日同刻样本数、历史均值、原值分位、有利方向分位及缺失原因。

新增诊断不形成第二个加权总分，也不改变正式准入权。历史不足保留原始观测；时效或覆盖不合格时，当前决策状态仍为未知。

计量版本为 `explicit-limit-observations-v2`，只采用可信的显式供应商涨跌停字段，不再把昨收乘以固定比例作为市场触板计量依据。无涨跌幅限制、停牌、公司行动及限价证据冲突的观察不参与限价统计。旧推算口径的档案不混入新基线。

日内最高价仅能支持“曾触价且当前未封”的比例，不能还原炸板次数、回封顺序或排队成交。市场情绪代理指标不等同于投资者心理或主力意图。

## 验证边界

相关后端、信号持久化、前端行为和构建检查验证代码实现与记录一致性，不验证投资收益。完整盘中模型仍需要同刻分钟量价、板块共振、交易压力证据，以及按时间隔离的训练、校准、留出验证和前向观察。

安装验证应比较冻结后端与源码、桌面和后端文件哈希，并核验启动后的算法契约。旧推荐记录保留原算法版本，不因软件升级被改写为v3结果。
