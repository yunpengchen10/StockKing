# v2.9.0：热门题材优先与每日反馈

2026-11-13。当前机会精选入口为 `opportunity-theme-20261113-v1`。

## 选股顺序

先建立当时可核验的概念题材榜，再研究主线中的核心股票，最后核验资金、持续走势与入场位置。行业分类继续用于行业资金与集中度控制，不替代概念题材。旧 E/M 和 11 月 3 日资金规则的历史记录保持原版本、原价格及原依据。

题材涨幅、上涨广度及概念成交额占比采用等权中位名次，最多选择三条主线。概念成交额存在成分重叠，其占比的分母为有效概念成交额之和，不是全市场成交额。题材相对强度是相对同源概念横截面中位数，不是指数超额收益。只有正涨幅、广度至少55%、相对强度为正且成分完整、有效报价覆盖达到80%的主题才能入选。

题材中的股票先按当时全体有效成分的涨幅名次判断领先地位。核心区为前30%、至少前三名，并要求不落后于题材涨幅；发布时再检查当前报价相对题材的强度。研究队列约80%预算优先主线，保留约20%其他发现对照，空余可互补。最终推荐仍限沪深主板非ST，每轮最多五只、每题材最多两只、每行业最多两只，不凑数。

个股和行业的同源30分钟资金、持续价格路径、盘口及ATR入场距离继续独立核验。热门题材不能覆盖这些缺口。通过约束后的顺序为题材名次、题材内领先名次、资金与走势质量、股票代码；短时加速度不恢复为主导条件。

## 数据与冷启动

使用明确的概念目录及完整成分，保留来源、源时间、首次可知时间和真实分母。东方财富概念接口不可用时，备用路径使用新浪概念目录与成分，以及软件获取的真实个股报价聚合；不使用新浪目录中无源时间的行情栏，也不把目录抓取时间当报价时间。备用目录采用有界渐进缓存，首次尚未完整时显示准备进度，不使用部分赢家拼成全市场题材榜。

备用路径的题材涨幅是有效成员等权平均，成交额是成员成交额合计，不冒称供应商概念指数。目录中成分数量冲突的概念仍计入完整概念覆盖分母；至少80%的目录概念形成有效统计后才启用排行，单个入选题材仍必须具有完整成员映射。

沪深全市场成员报价用于题材统计，创业板、科创板及ST成员不会因此进入主板推荐池。报价不足、目录不完整、盘前成交额尚未形成或请求超时均保留明确原因。网络采集继续受统一扫描截止时间和最终报价预算约束。

## 每日反馈

每轮冻结题材榜、当时推荐、未选对照和可选范围。收盘复盘写入独立 `theme-feedback-v1.sqlite3`，不改原账本和历史推荐。每股每日首个有效参考价及已核验收盘价不被后续重跑覆盖；缺行情可以补评，缺失的历史参考价不能事后补造。

反馈展示题材参考价后是否走弱、首轮入选组是否落后、参考价后回落和已冻结可选池内的漏选强股。当天后来已推荐的股票不再标作全天漏选；非主板成员仅参与题材统计。非主线的少量候选样本明确标为样本观察，不能冒充全题材广度。归因是价格证据描述，不是已经证明的因果关系。

下一交易日读取已知的前日反馈。至少三个独立日期、至少两次走弱且走弱占比达到一半，才按每次走弱0.02、合计最多0.1降低该题材的排序分。每个有效题材日需要至少三只同窗成员、完整成员分母及80%有效观察覆盖。反馈超过五个交易日或七个自然日失效。单日亏损、重复扫描或数据缺失不会触发调整，也不修改模型权重。

盘后界面可以立即读取最新已保存反馈，包含未取得收盘证据的失败状态；读取页面不触发扫描、复盘或训练。历史回看仍显示当时冻结的反馈。页面按“今日主线、核心股票、每日反馈”组织，并限制默认展开数量。

## 验证与边界

离线测试覆盖源时、未来数据隔离、完整分母、主线优先、缺题材不回退行业、原资金硬条件、首次发现保持、未选对照、当天后来入选、同日收盘、并发幂等、读取无副作用及完整跨日反馈到排序流程。前端使用真实Vue脚本与模板离线渲染，构建和测试不启动浏览器。

本次419项相关后端测试、174项前端测试通过，前端生产构建和Windows桌面构建成功。2026-11-13 09:18:32北京时间的真实只读探针取得172个新浪概念目录，其中162个成员映射完整；3205只去重沪深成员中实际返回3202只腾讯报价。当时所有返回报价的成交额均为零，程序保持盘前观察、未生成盘中热门主线。这验证了数据读取与盘前边界，不证明盘中推荐收益。

这些阈值是公开的研究起点，尚未证明未来收益改善。参考价至收盘变化不是成交收益；软件没有增加券商下单能力。每日反馈更新主线优先级，经过验证的独立预测模型仍沿用原训练和启用流程。
