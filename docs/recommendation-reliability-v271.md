# v2.7.1 推荐可靠性修订

本次修订解决行情初筛、对照保存、复盘积压和学习任务混用的问题。代码验收不代表已经证实收益提高。有效模型、样本或行情缺失时，正式推荐仍可为空；观察名单单独统计。

## 数据与覆盖

- 全池报价补强完成后重建深研队列，并补取新入队股票的日线证据。成交额、量比、换手和开盘修复各自核验供应商源时；新的价格时间不能给旧量比或换手续期。目录完整与报价新鲜分别报告。
- 板块采集按欠采情况轮转，各行业逐只轮流获得请求预算；同窗增量缓存降低重复请求。完整行业分母、至少 80% 覆盖及源时核验继续执行。
- 先对全部符合条件的候选分配行业额度，再截取前列，避免头部同业挤掉其他行业的合格候选。
- 日线拒绝记录关联当轮完整报价后冻结参考价。已经缺少原始报价的历史记录维持不可核验，禁止用之后价格修补历史起点。

## 独立复盘

日线观察使用独立的持久结算队列。每个标签的结果和重试检查点在同一事务提交；租约防并发，过期租约可恢复，批次有时间和数量上限。扫描与收盘复盘先推进日线队列，再运行较慢的分钟成交模拟。读取页面只展示结果和重新计算的到期状态，不触发结算。

界面显示待结算、逾期、缺行情及最近成功批次。成功批次不代表全部结果完整。不可核验参考价与缺少收盘证据分别呈现。T+1/T+3/T+5 的参考价变化属于价格观察，不是成交后净收益。

可运行 `scripts/reconcile-daily-observations.py` 对本地账本补评。默认对一致性副本试运行；`--apply` 先备份再更新派生结果，验证原始信号和模型未改变。该工具不补造数据、不训练、不发送通知。

## 学习与交易目标

- 数据、特征、标签和模型契约分别保存；历史复用须验证原始算法清单哈希以及白名单兼容投影，并保留原始训练资格。未知清单或影响标签/执行的变化继续拒绝复用。
- 不同任务独立审核：当日方向与次日价格事件不会因纯账户/入场区间调整而重置；T+1 成交收益会核验实际执行规则变化。
- 准备度按真实滚动训练、校准、留出与隔离日期计算，报告每折日期、样本和类别缺口。默认结构至少需要 156 个日期才可能留下最早折的训练数据，之后仍须满足样本和校准要求。
- 当日方向仅是独立观察。用于入场的模型必须针对可执行的 T+1 扣费收益：净收益大于零的概率为主头，净收益至少 5% 的概率为独立辅助头。辅助事件不足时显示缺失，不伪造概率，也不把它当成普通盈利概率。

## 数值入场约束

首次证据合格的报价冻结当日每股的研究入场计划。区间半宽取 `min(0.25 × ATR, 0.5% × 触发价)`，下界同时高于已核验支撑，价格按最小报价单位向内取整。有效期五分钟且不跨午休或收盘；重复扫描不重置触发价、失效价或截止时间。最终发布前再次核验报价、模型与冻结计划。

研究触发独立于模型是否已启用，以便保留未入选的可执行对照。正式入场同时需要证据、已验证的 T+1 模型、正净收益/效用和有效价格区间。回放使用发布后第一个完整分钟开盘价加滑点，再检查冻结区间、流动性和涨跌停；不能从分钟高低价倒推出一次有利成交。退出仍按下一交易日及费用/流动性规则。上述五分钟和距离参数是事先定义的风险偏好，未经收益最优化。

## 前向因子比较

保存五组影子分数：基线、去除重复突破分量、去除换手重叠分量、VWAP 位置分封顶、资金持续性。资金持续性仅使用同供应商、同窗连续四个累计观测形成的三个逐分钟增量；缺数、冲突、午休或未来点不产生指标。影子分数不改变当前推荐或自动发布模型。

`daily-engine/scripts/evaluate-factor-experiments.py` 读取明确导出的冻结记录。每个股票/交易日只取首次合格信号；各变体使用相同完整样本，缺失结果剔除整个日期，无法成交的明确结果记为现金零收益。必须提供含时区的决策、标签结束和可知时间；开发标签不得越过事先指定的留出边界，也不得使用截止时点之后的结果。报告是描述性对照，不是完整组合回测，不自动选出或上线最优变体。

运行示例：

```text
python daily-engine/scripts/evaluate-factor-experiments.py frozen-rows.json --holdout-start YYYY-MM-DD --as-of YYYY-MM-DDTHH:MM:SS+08:00 --output comparison.json
```

输入行包含 `day, code, decisionAt, labelEndAt, labelKnownAt, eligible, factorExperiments, outcomeStatus, netReturn`。`factorExperiments` 必须来自当时冻结快照，不能用事后重算分数代替。

## 验证范围

本次修改及相关成交回放、接口认证、任务隔离回归共 660 项 Python 测试通过，前端 129 项测试通过。Go 验证覆盖桌面入口、分钟行情包及改动涉及的本地数据转换与请求选择用例；未运行可能启动外部浏览器的爬虫测试。上述检查验证实现与故障处理，不构成实盘成功率或收益提升的证据。

本机更新保留原程序与一致性数据库备份。安装时先以停用状态注册计划任务，补评完成后再恢复原有启用状态，避免安装过程中提前运行扫描。
