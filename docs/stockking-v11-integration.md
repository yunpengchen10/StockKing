# Stock King V1.1：图表、精选与延后复盘

## 运行链路

Wails 图表和 Python 精选使用 Go 行情服务。桌面启动或 `--stock-king-task=<slot>` 后台启动均建立仅监听 `127.0.0.1` 的随机端口，使用进程生成的鉴权令牌；令牌只传给侧车环境，不进入前端或信号记录。

- `/v1/quotes`：复用腾讯/新浪原始报价缓存，分别保留来源时间和获取时间。
- `/v1/bars`：复用图表的通达信、东方财富、新浪、腾讯降级链及缓存，支持批量分钟与日线。
- `/v1/snapshot`：重新分页读取沪深主板，用固定代码排序并核对实际覆盖数量。
- `/v1/sectors`：已有板块接口。

分钟价格不复权、成交量为股、金额为元；未知金额为空。缓存中的未完成分钟不会在时间流逝后自动变成有效分钟。每日扫描最多深核30只，下一轮重新取全市场快照，每轮最多5只入选。

## 评分与数据不足

算法版本为 `stockking-v1.1-rules`。Early/MainRise 使用原始人工权重，可选因子缺失时按现有权重重新分配。初始最终分为 `clip(max(Early, MainRise) - 0.2 × DistributionRisk, 0, 100)`，0.2明确记录为未验证初值。

20日同刻基准完整，5–19日降低置信，不足5日的历史因子为空。新鲜报价、证券身份、完整分钟和交易状态仍须检查。阶段描述采用可观察价格结构；未经校准的主升概率和MFE预测为空。精选不调用大模型，独立AI研究功能保留。

## 记录与复盘

持久化位于用户数据目录 `daily/king-adaptive`：

| 文件 | 用途 |
|---|---|
| `signal-learning-v1.sqlite3` | 新版信号、深核对照、1/3/5日复盘、学习模型与影子预测 |
| `official-job-claims-v1.sqlite3` | 官方任务跨进程去重和最终结果 |
| `minute_history/minute-bars-v2.sqlite3` | 已有分钟归档，持续补充有效数据 |

推荐先保存再返回前端；旧 `stock-analysis.db` 的历史口径不回填。观察收益与模拟收益分开，模拟采用发布后下一完整分钟及期限收盘，费用与手数约束复用账户回测模块。盘口、涨跌停和数据不能支持成交时，不记作用户成交。旧历史和新版训练样本隔离。

## 学习与更新

仅新版确认样本进入独立学习库。默认至少120个成熟独立交易日、1000个有效样本；按时间划分训练、校准、检验区间，边界隔离至少5个交易日。模型通过扣费账户收益、相对现行策略优势和回撤检验后，才开始20交易日前瞻影子验证；任何必要数据或执行证据不足都不允许晋升。推理或模型版本出错回退已验证版本或规则。

Windows更新使用 `scripts/update-windows-local.ps1`：先暂存与哈希核验、SQLite一致性备份、保留旧可执行文件和侧车目录，再替换安装并核验7个计划任务。备份清单保存在安装目录 `backups/update-<时间>/manifest.json`。

自动任务依赖系统能够运行程序。Windows任务沿用当前用户登录会话；机器关机或未登录时不能保证按时执行，错过后不会补造当时的信号。
