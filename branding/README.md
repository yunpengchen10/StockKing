# Stock King 标志 / identity

v2.4 使用独立设计的 K 字母几何标志：深海军蓝底、白色与蓝色线条。SVG、PNG 和 Windows ICO 均由 `scripts/generate-brand-assets.py` 的同一组几何路径生成，适配导航、桌面和安装器。界面动作色与行情红涨绿跌相互独立。

The v2.4 K monogram uses shared original geometry for SVG, PNG and multi-resolution ICO assets. Run `scripts/generate-brand-assets.py` to reproduce them.

`stock-king-logo-source.png` 保留为此前已授权的历史资产；当前生成器不再使用它。项目资产随 Stock King 依 GPL-3.0 分发，第三方归属见仓库声明。
